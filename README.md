# Приложение для поиска и прослушивания музыки

Проект представляет собой приложение для поиска и прослушивания музыки.

## Главный экран -- экран медиатеки

На этом экране пользователь может видеть "избранные треки" и взаимодействовать с ними. А также перейти на экран "Плейлисты", 
на котором можно создать новый плейлист из избранных треков и взаимодействовать с ним.

## Экран поиска

На этом экране пользователь может искать музыкальные треки по любому непустому набору слов поискового запроса. Результаты поиска
представляют собой список, содержащий краткую информацию о треках.
Также этот экран отображает историю поиска треков, ранее с которыми взаимодействовал пользователь. При помощи кнопки "Очистить историю" 
пользователь может очистить список треков, с которыми он ранее взаимодействовал.

## Экран просмотра деталей трека

Нажав на элемент списка найденных треков (аналогично в списке избранного), пользователь попадает на
экран с подробным описанием трека. Экран отображает информацию о треке: название трека, альбом, длительность трека,
год выхода трека, жанр, страна выхода трека. Помимо информации о треке, пользователь может взаимодействовать с треком:

- Нажав на кнопку "Play" трек начнёт проигрываться и под кнопкой запуститься таймер. Повторное нажатие на кнопку
поставит трек на паузу. По истечении 30 секунд трек прекратит своё воспроизвидение согласно политике iTunes Search API; 
- Нажав на кнопку "Playlist" пользователю откроется высплывающее окно с возможностью добавить трек в существующий
плейлист или создать новый плейлист;
- Нажав на кнопку "Like", кнопка поменяет цвет указывая пользователю на добавление трека на экран "Медиатека" "Избранные треки".
Повторное нажатие убирает трек из избранных. 

## Экран настройки

На этом экране пользователь может:

- Поменять тему приложения на тёмную, и наоборот;
- Поделиться приложением;
- Написать в поддержку: пользователя направит на выбранную им почту;
- Ознакомиться с пользовательским соглашеием: пользователя направит на сайт правовых документов Яндекс Практикума.

## Экран создания плейлиста

На этом экране пользователь может создать плейлист выбрав изображение для будущего плейлиста, написать название (обязательный пункт для создания плейлиста)
и написать описание для плейлиста.

## Экран плейлист

Пользователю доступно описание, название плейлиста, ранее выбранное им изображение для плейлиста, а также добавленные им треки.
На этом экране доступен следующий функционал:

- Нажатием на кнопку "Share" пользователь может поделиться плейлистом;
- Нажатие на кнопку "Options" пользователю покажется всплывающее окно. В всплывающем окне он может поделиться плейлистом, редактировать плейлист,
а также удалить плейлист.
